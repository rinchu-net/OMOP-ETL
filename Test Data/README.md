# 臨中ネット OMOP ETLツール用テストデータ

臨中ネット OMOP ETLツールの動作確認・検証に使用するサンプルデータです。  
**本データは合成データであり、実在の患者情報は一切含まれていません。**

## 概要

本データセットは、OHDSI の Eunomia サンプルデータセット 「Synthea27Nj」 を基に作成しています。  
Synthea27Nj は、Synthea™（The MITRE Corporation）が生成した合成患者データを OMOP CDM へ変換したものです。

本データセットでは、これを臨中ネット ETL ツールの入力形式（ソースデータ形式）へ再構成しています。  
データの流れは以下のとおりです。

```
Synthea (MITRE)
  └─ OHDSI/ETL-Synthea で OMOP CDM 5.4 へ変換
       └─ Synthea27Nj (OHDSI EunomiaDatasets)
            └─ 本ディレクトリ: 臨中ネットのソースデータ形式へ再構成
                 └─ 臨中ネット OMOP ETLツール で OMOP CDM へ変換（検証対象）
```

## 使用方法

1. 本ディレクトリの CSV ファイル一式を、臨中ネット OMOP ETL ツールの入力フォルダへコピーします。

```
   \rinchu-omop\3000_load_source\dat
```

2. 臨中ネット OMOP ETL ツールを実行します。

3. ETL 処理完了後、生成された OMOP CDM データを確認してください。

## 元データと加工内容

| 項目 | 内容 |
|------|------|
| 元データセット | Synthea27Nj（OHDSI Eunomia サンプルデータセット） |
| 取得元 | https://github.com/OHDSI/EunomiaDatasets/tree/main/datasets/Synthea27Nj |
| 取得ファイル | `Synthea27Nj_5.4.zip` |
| OMOP CDM バージョン | 5.4 |
| ボキャブラリバージョン | v5.0 09-APR-22（Vocabulary Shard） |
| 元データのリリース日 | 2022-10-10（`CDM_SOURCE.csv` の `source_release_date` / `cdm_release_date`） |
| 元データのETL | [OHDSI/ETL-Synthea](https://github.com/OHDSI/ETL-Synthea) |
| 患者数 | 28件（`PERSON.csv` の `person_id` 件数） |
| 取得日 | 2026-06-24 |

> **バージョン表記について**
> `Synthea27Nj_5.4.zip` の `5.4` は OMOP CDM のバージョンです。  
> Synthea 本体のバージョンは元データセットに記録されていません。

本データセットでは、臨中ネットの入力仕様に合わせて以下の加工を行っています。

- OMOP CDM 形式（Synthea27Nj）のテーブルから、臨中ネット ETL ツールの入力 CSV 形式へ再構成
- 患者 ID を32桁のハッシュ値へ置換（元データの識別子は保持していません）
- 元データに含まれる標準概念（SNOMED CT / LOINC / RxNorm / UCUM）を、日本国内で用いるソースコードへ置き換え
  - 病名: SNOMED CT → ICD-10コード／日本語病名
  - 検査: LOINC → JLAC11（一部JLAC10）コード（17桁）／検査項目名／検体材料コード
  - 薬剤・注射: RxNorm → YJコード／臨中ネット標準コード／日本語医薬品名
  - 来院: HL7 ADTセグメント（`ADT^A01^ADT_A01` 等）
- 日付は元データの値をそのまま保持（全体の範囲: 1955-03-07 〜 2022-10-10）
- 元データの `DRUG_EXPOSURE` を、処方（`PrescriptionData.csv`）と注射（`InjectionData.csv`）に分割

> **ETL との対応**  
> 置き換え後のコードは、ETL ツールの `source_to_concept_map` に登録済みのものを使用しています。  
> これにより ETL 実行時に標準概念へ変換されます。  
> 裏を返せば、`source_to_concept_map` に登録のないコードを追加しても標準概念へは変換されません。

## 注意事項

- 本データはテスト・検証用途専用です。実運用・臨床判断・研究用のデータとして使用しないでください。
- 本データは機械的に生成された**合成データ**です。実データと混在させたり、実データと誤認される形で保管・配布したりしないでください。
- 臨中ネット向けの検証を目的として一部データを加工しているため、Synthea が本来出力する統計的分布や臨床的整合性は保たれていない場合があります。機械学習の学習データや疫学的分析には適しません。
- 日本語医薬品名・YJコードは実在の医薬品のものですが、処方の内容は合成データであり、臨床的な妥当性を保証するものではありません。

## 収録コードについて

本データセットには SNOMED CT、LOINC、RxNorm 等の国際標準用語コードは**含まれていません**。  
元データセット Synthea27Nj にはこれらの概念を収めたボキャブラリシャード（`CONCEPT.csv` 等）が同梱されていますが、本データセットではソースコードへ置き換えたうえで、ボキャブラリ関連テーブルは収録していません。

標準概念へのマッピングは ETL ツール側の `source_to_concept_map` テーブルで管理しており、本データセットの範囲外です。  
したがって、本データセットの利用・再配布にあたって各用語管理団体の利用条件は適用されません。

なお、ETL 実行後に生成される OMOP CDM データには標準概念（SNOMED CT 等）が含まれます。  
これを第三者へ配布する場合は、OHDSI Athena のボキャブラリ利用条件および各用語管理団体の条件を別途ご確認ください。

## Overview (English)

Synthetic test data for the Rinchu-Net OMOP ETL tool. **No real patient data is included.**

Derived from the OHDSI Eunomia sample dataset [Synthea27Nj](https://github.com/OHDSI/EunomiaDatasets/tree/main/datasets/Synthea27Nj) (OMOP CDM 5.4, released 2022-10-10), which was generated by [Synthea™](https://synthetichealth.github.io/synthea/) and converted via [OHDSI/ETL-Synthea](https://github.com/OHDSI/ETL-Synthea). The OMOP CDM tables have been restructured into the source-data format consumed by the Rinchu-Net ETL tool, with standard concepts replaced by Japanese source codes.
