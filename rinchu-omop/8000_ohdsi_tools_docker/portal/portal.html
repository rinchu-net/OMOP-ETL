アクセス情報と使用方法

プロトコル

すべてのサービスは HTTP で提供されています。

データ永続性

データベースとpgAdminの設定は Docker ボリュームで保存されています。
コンテナ再起動後もデータは保持されます。

コンテナ管理

起動: controller.bat start
停止: controller.bat stop
再起動: controller.bat restart

OMOP CDM について

OMOP CDM（Observational Medical Outcomes Partnership Common Data Model）は、医療データを標準化されたフォーマットに変換するための国際的なデータモデルです。異なるソースのヘルスケアデータを一貫した形式で分析できるようにします。

サービスに接続できない場合

  • コンテナが起動しているか確認: docker ps で確認してください
  • ファイアウォール設定: 指定されたポートがブロックされていないか確認してください
  • ポート競合: 別のアプリケーションが同じポートを使用していないか確認
  • メモリ不足: Docker に十分なメモリが割り当てられているか確認（推奨: 8GB以上）
  • ログ確認: docker logs <container_name> でエラーログを確認

本ポータルは開発/テスト環境向けです。本番環境での使用時はセキュリティ設定の見直しをしてください。
